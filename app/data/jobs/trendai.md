## Overview

AI is transforming the way we approach cybersecurity. TW Engineering Group 1 focuses on building innovative endpoint security solutions that solve real-world challenges.

We look for forward-thinking engineers who leverage AI to enhance productivity, challenge the status quo, and create high-quality solutions that make a real difference for our customers.

## Your Mission

1. Leverage AI-assisted development tools (e.g., GitHub Copilot, ChatGPT or MCP servers) to boost development speed, enhance code quality, and accelerate prototyping.
2. Collaborate closely with stakeholders on requirement discussions, cross-team integration, and issue resolution.
3. Deliver features through the full development lifecycle, including planning, design, implementation, testing, deployment, and operation.
4. Create and execute test cases and scripts to validate software functionality, performance, reliability, and security.
5. Troubleshoot and debug complex issues by identifying root causes and implementing effective solutions.
6. Automate and enhance development and release processes to improve efficiency and reliability.

## What We’re Looking For

1. Bachelor’s degree in computer science, engineering, or equivalent industry experience.
2. Familiarity with one of the programming languages (e.g. Golang, Python, Java, Node.js, C#)
3. Familiarity with one of the testing frameworks (e.g. Selenium, pytest and Robot Framework).
4. Familiarity with microservice architectures and REST API development
5. Familiarity with development relational or NoSQL databases, (e.g. PostgreSQL, MySQL and Redis)
6. Familiarity with version control systems (e.g. Git) and CI/CD processes (e.g. GitHub Action)

## Extra Skills We Love

1. Experience in developing cloud service solutions using AWS, Azure, or GCP.
2. Experience in container solution (e.g., Docker/K8S)
3. Experience in Infrastructure-as-Code (IaC) tools (e.g., Terraform, CloudFormation)
4. Experience in monitoring, alerting, and log visualization tools (e.g. Elasticsearch and Kibana)
5. Experience in test management platforms (e.g.TestRail)
6. Able to visualize design and test logic to improve test coverage and catch edge cases.
